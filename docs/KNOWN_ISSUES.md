# 已知限制

- iOS需要用户分别在系统设置添加26键和九宫格，并分别开启完全访问。此前设备诊断显示只启用了九宫格；两个扩展始终在包内，本轮源码整理不能证明26键已在系统恢复。请以手机设置列表为准。
- 自定义接口通过翻译测试不等于支持分析的结构化格式；不支持时应显示分析失败，不影响已返回的译文。
- AOSP词库是固定的历史版本，九宫格为有界近似搜索，不保证现代商业输入法的纠错/预测质量。
- 英文分析由模型生成；边界和格式校验不能保证语法、含义或翻译永远准确。
- 单词含义随当前句分析生成；未准备好时显示等待状态，旧格式或遗漏的词义明确显示暂未提供，不临时猜词义或另发查词请求。长句分析可能需要更久，输出用量随词数增加。
- 千问听读需要同一北京地域Key拥有语音模型权限及可用额度；翻译测试通过不代表语音权限可用。首次生成依赖网络，不承诺立即出声。当前按官方单次600字符限制处理，超过时明确提示，不截断或自动拆成额外付费请求。
- 音频只缓存在当前键盘会话；离开后再听需重新生成。取消会停止本地请求/播放，但服务端若已经接受生成，仍可能计费。键盘内真实音频路由、静音开关、来电及微信语音中断需要真机听测。
- 键盘扩展不能遮盖或控制微信整页，学习区按约半屏预算请求高度。系统地球/麦克风条由iOS管理。
- 宿主文本替换不是原子操作。异常或用户同时编辑时可能需要核对输入，程序只在精确匹配时尝试回滚。
- 本地Catalyst验证不能代表真机触摸、真实大字体和长期闲置体验。尚未声明支持iPad。
