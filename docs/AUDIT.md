# 工程审查 · 0.1.0 (28)

日期：2026-09-08。本轮覆盖 App 页面、键盘生命周期、翻译/分析异步状态、替换、拼音桥、工程资源与可复现构建。它不等于完整安全审计或所有真机行为保证。

## 已复现并修复

| 问题 | 修复 | 回归证据 |
| --- | --- | --- |
| 订阅者在翻译状态发布中同步更改输入，旧输入仍可能启动请求 | 发布前捕获 revision，序列化重入状态，派发前再校验 | LiveHintCore 的状态重入和取消测试 |
| 对象释放后翻译/分析任务仍存活 | 避免 await 期间强持有模型，分析会话析构时取消 | owner-release 与迟到结果测试 |
| 宿主失活但控制器未消失时，删除循环和请求仍继续 | 统一失活清理，检查可见与活跃状态；仅暂时失活时保留组合输入 | 真实 UIKit 控制器，2 条通知路径及 39 项检查 |
| 切换数字/符号/英文大小写键面后，替换/分析/撤销入口消失 | 纯键面变化保留当前文档快照；实际输入编辑仍使旧状态失效 | 键面变化与撤销生命周期测试 |
| 早期诊断文件仍可在正式版写入 | 诊断缓存和文件写入限定 DEBUG | Release 编译检查；安全的拼音 OSLog 状态保留 |

## 工程整理

- 仓库根就是 Xcode 工程根；App 入口从约1300行拆成按功能的页面与设计组件。
- AppIcon 使用1024×1024资源；关于页保留用户原图。没有重绘或裁剪 Logo 内容。
- 个人签名放在忽略的 Local.xcconfig；生成器不写入个人团队，三个 target 与 bundle ID 稳定。
- 删除正式 App 中临时自检入口和未公开系统键盘状态诊断。
- 旧源目录、演示页面、参考工程、旧包和日志移到项目外归档，先快照再移动，没有永久删除历史源文件。
- 测试使用稳定入口，无版本专用路径。依赖来源、许可和本地补丁继续保留。

## 验证与边界

- 八套离线回归通过：核心状态、设置、云端翻译、替换、分析、分析会话、学习高度、真实拼音/T9。
- 真实拼音桥运行 AddressSanitizer 与 UndefinedBehaviorSanitizer；仅操作临时测试字典。
- 分析数据177项检查；分析会话13组37断言；键盘控制器39项检查。
- 主App真实Mac Catalyst渲染18状态、117项检查，覆盖浅深色、小屏和辅助功能布局分支；编译后的原品牌资产加载成功。不是iPhone截图或实际iPhone大字验证。
- 仓库检查覆盖目标/源码/资源引用、版本、图标、生成项目一致性、忽略规则和高置信密钥特征。特征扫描不构成所有潜在敏感信息的保证。
- GitHub Actions独立运行离线测试与无签名Release构建，保留7天构建包供开发者在本机签名。当前提交是否通过以对应Actions运行记录为准。
- 本机Xcode首次Release构建在asset catalog阶段因缺少模拟器运行时失败；系统盘空间不足以安装该组件。没有因此删除用户其他文件或降低工程目标版本。
