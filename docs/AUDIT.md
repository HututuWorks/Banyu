## 工程整理

- 仓库根就是 Xcode 工程根；App 入口从约1300行拆成按功能的页面与设计组件。
- AppIcon 使用1024×1024资源；关于页保留用户原图。没有重绘或裁剪 Logo 内容。
- 个人签名放在忽略的 Local.xcconfig；生成器不写入个人团队，三个 target 与 bundle ID 稳定。
- 删除正式 App 中临时自检入口和未公开系统键盘状态诊断。
- 旧源目录、演示页面、参考工程、旧包和日志移到项目外归档，先快照再移动，没有永久删除历史源文件。
- 测试使用稳定入口，无版本专用路径。依赖来源、许可和本地补丁继续保留。
