# 数据处理说明

- 苹果模式在设备上翻译；首次准备语言包可能需要Apple系统联网下载。苹果模式不会使用留存的云端Key发分析或语音请求。
- 千问/自定义只有在主App显式启用后才生效。翻译发送光标附近的当前短句；学习提前发送对应英文，即使用户没有展开。
- 不读取完整聊天记录、不自动发送消息。系统文本代理提供的上下文仅用于当前输入与准确替换检查。
- API Key及服务配置存在App和两个扩展共享的设备钥匙串，禁用iCloud同步，限定当前设备。服务域名改变时不能复用旧Key。
- 网络响应不缓存、不自动重定向；翻译和分析结果缓存仅在内存中。旧输入/设置/权限/生命周期变化后隔离旧结果。
- 千问语音只在用户点小喇叭后发送当前英文。翻译与语音复用同一千问配置，但语音生成单独计费。音频下载不携带API Key；单句音频仅在当前键盘会话内存中复用，编辑、宿主失活/隐藏、设置变化或内存告警时清理，不保存声音文件、不录音。
- AOSP拼音引擎会在扩展沙盒保存选词学习字典。源码仓库和本地测试不携带真实用户字典。
- Release不保存早期翻译诊断缓存；DEBUG诊断仅有界事件元数据，不包含输入原文、译文、候选或密钥。拼音初始化失败可保留不含正文的系统错误日志。

这份文档描述当前实现，不代替未来上架时对第三方服务条款、App Store数据声明和真实发布配置的审查。
